# ID Card Studio
当前黑黄配色版本。无需安装依赖。

## 文件
- index.html：页面
- styles.css：样式
- app.js：照片处理、实时绘制和 PNG 下载

## 使用
直接打开 index.html，或用任意静态网页服务器运行。
上传头像和全身照片，填写资料，勾选确认后生成并下载。
所有照片和输入仅在浏览器内存中处理；本版本没有服务器上传、云端保存或数据收集功能。

## GitHub Pages
将本目录中的文件放到仓库根目录。在仓库 Settings → Pages 中选择 Deploy from a branch，选择 main 分支和根目录，保存。
不要将个人照片、密钥或未打算公开的文件放入仓库。

## 可选上传功能（未包含）
可以新增单独的“自愿上传生成卡片”勾选和上传按钮，并明确说明将保存的内容及用途。
前端生成 PNG 后，需调用独立后端接口，将图片写入私有存储。
GitHub Pages 仅承载静态前端，不能独自接收和保存上传。
服务器需负责上传限制、身份与访问控制、删除以及保存期限；管理员密钥仅保存在服务器。
